點讀 (DimDuk) — 隱私權政策

最後更新日期：2026年10月

1. 簡介

「點讀」（以下簡稱「本擴充功能」）是一款專為香港中學生而設的中文閱讀延伸工具，由大學生作為畢業專題研究項目開發。本隱私權政策說明我們如何收集、使用、儲存及保護你的資料。

使用本擴充功能即表示你同意本政策所述的資料處理方式。如你不同意，請停止使用本擴充功能。

2. 我們收集的資料

2.1 儲存於你本機瀏覽器的資料（不會上傳）

以下資料僅儲存於你的瀏覽器本機（IndexedDB），不會傳送至我們的伺服器：

資料類型 內容
個人設定 年級、閱讀水平、學習模式偏好、閱讀目標
閱讀紀錄 閱讀時段、頁數、時長、連續閱讀天數
詞彙紀錄 查詢過的詞語、定義、粵音、掌握程度
句子收藏 你收藏的句子及筆記
對話紀錄 你與 AI 的對話歷史
練習紀錄 練習題目、你的答案、分數
讀後感 你撰寫的反思內容、評分、標籤
知識點紀錄 你查看及收藏的知識點
你可以隨時透過擴充功能的設定頁面匯出或刪除這些資料。

2.2 傳送至我們伺服器的資料

為提供 AI 相關功能，以下資料會傳送至我們的伺服器（經 Supabase Edge Functions 處理）：

資料類型 用途 傳送時機
你選取的文字 提供詞語解釋、語譯、賞析 當你使用查字詞或語譯功能時
你正在閱讀的篇章內容 提供知識點辨識、練習生成、AI 對話 當你使用相關功能時
你與 AI 的對話內容 提供 AI 引導回應 每次對話時
你的年級及閱讀水平 調整 AI 回應的難度 每次 AI 請求時

2.3 你自願提供的資料

資料類型 用途 是否必須
稱呼（回饋表單） 聯絡你進行訪談 否，自願填寫
電郵或電話（回饋表單） 聯絡你進行訪談 否，自願填寫

3. 我們如何使用你的資料

我們僅將收集的資料用於以下目的：

用途 說明
提供核心功能 詞語查詢、語譯、賞析、知識點辨識、練習生成、AI 對話、語音朗讀
個人化學習 根據你的年級、閱讀水平及學習進度調整內容難度
改善服務 分析使用情況以改進功能（僅使用匿名化或彙總數據）
學術研究 用於畢業專題研究項目的評估與分析
我們不會將你的資料用於：
  • 出售或出租給第三方
  • 廣告投放
  • 判斷信用或貸款資格
  • 與本擴充功能單一用途無關的任何目的

4. 第三方服務

本擴充功能使用以下第三方服務，你的資料可能會傳送至這些服務：

服務 用途 資料處理方式
Supabase 後端服務（Edge Functions、資料庫） 處理 AI 請求、儲存課程知識庫；伺服器位於雲端
AI 模型供應商（如 DeepSeek、Qwen） 生成 AI 回應 接收你選取的文字及閱讀篇章內容以生成回應
字典 API（如萌典） 提供詞語解釋 接收你查詢的詞語
語音合成服務（如 Azure TTS） 提供粵語發音 接收需要朗讀的文字
書目資料 API 提供書籍推薦 接收查詢條件
我們僅向這些服務傳送提供功能所需的最少資料。這些第三方服務有其各自的隱私權政策，建議你查閱。

5. 資料儲存與保留

資料類型 儲存位置 保留期限
本機學習紀錄 你的瀏覽器（IndexedDB） 直至你自行刪除或解除安裝擴充功能
AI 請求資料 Supabase Edge Functions 僅在處理請求期間短暫保留，不作長期儲存
回饋表單資料 我們的資料庫 直至研究項目完成後銷毀

我們不會無限期保留你的個人資料。

6. 資料安全

我們採取以下措施保護你的資料：

  • 所有與伺服器的通訊均使用 HTTPS 加密
  • Supabase Edge Functions 啟用 JWT 驗證
  • 資料庫啟用 行級安全策略（RLS）
  • API 金鑰儲存於伺服器端，不會包含在擴充功能中
  • 本機資料儲存於瀏覽器沙盒環境，其他網站無法存取
然而，請注意：沒有任何網路傳輸或電子儲存方式是完全安全的。我們無法保證絕對安全，但會盡力保護你的資料。

你有權：

權利 如何行使

刪除你的本機資料 透過設定頁面清除，或解除安裝擴充功能

聯絡我們查詢或投訴 發送電郵至下方聯絡地址

8. 兒童隱私

本擴充功能主要面向香港中學生（約 12 至 18 歲）。我們不會刻意收集 13 歲以下兒童的個人資料。如你是家長或監護人，發現你的子女向我們提供了個人資料，請聯絡我們，我們會盡快刪除。

9. 政策變更

我們可能不定期更新本隱私權政策。更新後的版本將發布於此頁面，並更新「最後更新日期」。重大變更時，我們會透過擴充功能內的提示通知你。

建議你定期查閱本政策。
